GitHub Pages로 개인 홈페이지를 만들었다. 이 글은 글쓰기가 실제로 돌아가는지
확인하려고 쓴 첫 글이다.

## 글은 이렇게 추가한다

1. `blog/posts/` 안에 `.md` 파일을 하나 만든다. 파일 이름이 곧 주소가 된다.
2. `blog/posts/posts.json`에 항목을 하나 추가한다.
3. 커밋하고 푸시한다. 1분 안에 반영된다.

`posts.json` 항목은 이렇게 생겼다.

```json
{
  "slug": "hello-world",
  "title": "홈페이지를 만들었다",
  "date": "2026-08-09",
  "tags": ["기록"]
}
```

`slug`는 `.md` 파일 이름과 정확히 같아야 한다. 확장자는 뺀다.

## 쓸 수 있는 문법

일반적인 마크다운은 다 된다.

- 목록, **굵게**, *기울임*, `인라인 코드`
- [링크](https://github.com/FoxOnTheGroove)
- 인용문과 표

> 인용문은 이렇게 보인다.

| 항목 | 설명 |
| --- | --- |
| 제목 | `posts.json`의 `title` |
| 날짜 | `YYYY-MM-DD` 형식 |
