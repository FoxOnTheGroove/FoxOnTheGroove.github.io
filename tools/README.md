# Private Isles 관리

링크 목록은 PC에서만 고친다. 폰에서는 보기만 한다.

## 파일이 어디에 있나

| 파일 | 커밋됨 | 내용 |
| --- | --- | --- |
| `assets/data/isles.json` | **아니오** | 평문 목록. 내 PC에만 있다. |
| `assets/data/isles.enc` | 예 | 암호화된 목록. 이것만 올라간다. |

`isles.json`은 `.gitignore`에 들어 있다. 실수로 올리는 걸 막으려는 것이니
빼지 말 것. 반대로 **이 파일은 백업 대상이다.** 날리면 금고를 열어서
되살려야 한다.

## 목록 고치기

1. `assets/data/isles.json`을 연다.

   ```json
   {
     "columns": 4,
     "sites": [
       { "name": "GitHub", "url": "https://github.com/" }
     ]
   }
   ```

   `columns`가 격자 열 수, `name`이 아이콘 아래 이름이다.

2. 아이콘을 채운다.

   ```
   python tools/fetch_icons.py
   ```

   `icon`이 비어 있는 항목만 사이트에서 받아와 64px PNG로 줄여 넣는다.
   직접 만든 아이콘을 쓰려면 `icon`에 파일 경로를 적고 다시 돌린다.
   못 구한 항목은 이름 첫 글자 배지로 나온다.

3. `tools/lock.html`을 브라우저로 연다.
   - 2번 칸에서 「평문 파일 불러오기」로 `isles.json`을 넣는다.
   - 3번 칸에 비밀번호를 두 번 넣고 「isles.enc 만들기」를 누른다.
   - 만든 자리에서 다시 열어보는 것까지 자동으로 확인한다.

4. 받은 `isles.enc`를 `assets/data/`에 덮어쓰고 커밋한다.

## 잠금이 어떻게 걸려 있나

봉투 암호화다. 목록은 무작위 키(DEK) 하나로 잠그고, 그 DEK를 두 가지 방법으로
각각 잠가 둔다.

- **비밀번호** — `isles.enc` 안에 들어 있다. 어느 기기에서나 통한다.
- **지문** — 그 기기의 `localStorage`에만 있다. 등록한 기기에서만 열린다.

그래서 PC에서 편집할 때 폰 패스키가 필요 없고, 폰에 지문을 등록해도 서버
파일을 고칠 필요가 없다.

한 번 열면 10분간 다시 묻지 않는다. 그동안 키가 `sessionStorage`에 남아
있으므로, 자리를 뜰 때는 「지금 잠그기」를 누르는 게 낫다. 탭을 닫으면
유예도 함께 끝난다.

## 조심할 것

- **비밀번호를 잊으면 끝이다.** 복구 수단이 없다. 폰을 잃으면 비밀번호가
  유일한 통로다.
- **비밀번호를 바꿔 금고를 새로 만들면 폰의 지문 등록이 무효가 된다.**
  폰에서 비밀번호로 한 번 열고 지문을 다시 등록해야 한다.
- **아이콘을 별도 파일로 두지 말 것.** 파일 이름(`github.png`)이 목록을
  누설하고, 이름을 해시로 바꿔도 이미지를 열어 보면 어느 사이트인지 드러난다.
  그래서 data URI로 암호문 안에 넣는다.
- **이 저장소는 public이다.** 페이지가 있다는 사실과 그 주소는 숨겨지지
  않는다. 실제로 지켜주는 것은 암호화뿐이다.

## 검증

`vault.js`는 Node에서 왕복 시험을 통과했다. 다시 돌리려면 WebCrypto가 있는
Node 18 이상에서 `require('./assets/js/vault.js')` 후 `create` →
`openWithPassword`를 확인하면 된다.
